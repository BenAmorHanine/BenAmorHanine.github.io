# Hanine Ben Amor · Portfolio

Static site for GitHub Pages. No build step.

## Put it online
1. On GitHub, create a **public** repository named exactly `BenAmorHanine.github.io`.
2. Upload everything in this folder (index.html, content.js, README.md, the assets folder).
3. Repository **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
4. After 1–2 minutes the site is live at https://benamorhanine.github.io

## Add your photo
Save a square photo as `assets/photo.jpg` and upload it. Until then, your initials are shown.

## Edit content
All text is in `content.js`, in English (`en`) and French (`fr`).
To add an experience, copy one block in `experience.items` (in both languages) and edit it.
To link a project to its repo, add `link: "https://github.com/..."` to that project.

## Update the CV
Replace the files in `assets/cv/` and keep the same file names.
